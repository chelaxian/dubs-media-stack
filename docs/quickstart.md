# Установка одной командой

Проект приватный. Сначала авторизуйте GitHub CLI через `gh auth login` и получите
исходники либо скачайте исходный архив из страницы релиза. Токены в команды и URL
вставлять не нужно. Поддерживаются Debian 12/13 и Ubuntu 24.04 внутри LXC/VM или
на отдельной машине. Запуск непосредственно на гипервизоре Proxmox запрещён.

Готовый проверенный исходный релиз:

```sh
gh release download server-2026.11.05 --repo chelaxian/dubs-media-stack --pattern 'dubs-media-stack-*.tar.gz' --pattern '*.tar.gz.sha256'
sha256sum -c *.tar.gz.sha256
```

В этом релизе также есть мобильные клиенты. Если скачан только исходный архив,
проверьте его отдельной контрольной суммой `.tar.gz.sha256` из того же релиза;
общий `SHA256SUMS.txt` предназначен для полного набора загруженных артефактов.

Из клона или распакованной папки релиза:

```sh
sudo ./install.sh
```

Визард спросит каталог **уже смонтированного** медиадиска, каталог данных приложений,
UID/GID владельца медиа и часовой пояс. Параметры сохраняются в приватный `.env`;
существующий файл не перезаписывается. Каждый изменяющий систему шаг требует
подтверждения. Затем меню позволяет установить зависимости и сервисы, создать
настройки, выполнить привязку сервисов и проверить готовность.

Первая установка требует настройки учётных записей Jellyfin/MyShows и ключей API
Sonarr/Prowlarr: визард создаёт JSON-шаблоны и указывает недостающие поля. Это не
авторизация в чужих аккаунтах и не автоматический подбор паролей. До заполнения
владельцев и параметров безопасности вход в панель закрыт. После заполнения
выполните шаги «bootstrap» и «Проверить готовность»; при ошибках визард не сообщает
об успешной установке. Схемы полей и настройка TLS:
[руководство](../README.md), [reverse proxy](security-reverse-proxy.md).

Диагностика без изменений и параметры запуска:

```sh
./install.sh --plan
./install.sh --help
python3 -m installer --help
```

Для существующего стека можно указать его файл параметров:

```sh
sudo ./install.sh --env-file /opt/dubs/compose/.env
```

## Обновление

Из клона или новой распакованной версии:

```sh
sudo ./update.sh --env-file /opt/dubs/compose/.env
```

После подтверждения сначала создаётся резервная копия конфигурации и состояния.
Обновляются код и уже работающие сервисы. Остановленные сервисы не запускаются,
медиа и пользовательские `.env` не заменяются. При локальных изменениях в Git
обновление отказывается выполнять `pull`. Из архива используются исходники именно
распакованного релиза; версия указана в `SOURCE_COMMIT.txt`.

## Проверка релиза

Страница GitHub Releases содержит исходный архив с визардом, контрольные суммы,
APK телефона/ТВ и IPA для TrollStore. `install.sh` и `update.sh` — точки входа
**внутри полного исходного архива**, отдельно от него они стек не устанавливают.
Артефакты клиентов могут иметь другой исходный коммит, если релиз меняет только
серверную часть: происхождение указано в описании релиза.

```sh
sha256sum -c SHA256SUMS.txt
tar -xzf dubs-media-stack-<commit>.tar.gz
cd dubs-media-stack
sudo ./install.sh
```

## Общий приоритет озвучек

Настройки → «Общий приоритет озвучек»: перетащите студии вверх/вниз либо используйте
кнопки ↑/↓, затем нажмите «Сохранить порядок». Приоритет общий для устройств.
«Применено» появляется после подтверждения правил Sonarr; при ошибке выполняется
повторная попытка. Индивидуальная озвучка сериала остаётся первой, обязательный
русский язык и ограничения качества сохраняются. Сохранение само по себе не
запускает скачивание и не удаляет существующие файлы.
