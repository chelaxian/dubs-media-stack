# Проверка зависших торрент-загрузок

Сначала различайте приём задания клиентом и реальную передачу: проверяйте
`status`, `errorString`, `downloadedEver`, `rateDownload`, `peersConnected`,
`peersSendingToUs`, `trackerStats` через Transmission RPC. HTTP/RPC-секреты и
полные announce-URL с passkey не публикуйте.

1. Убедитесь, что выбранные файлы включены, есть свободное место, каталог доступен
   на запись и торрент не остановлен. Проверьте очередь и ошибки локальных данных.
2. Сравните infohash одинаковых по названию раздач. При совпадении у публичных
   торрентов можно объединить трекеры; при различии это разные рои.
3. Сравните заявленные сиды каталога с текущими announce/scrape ответами.
   `Success` означает ответ трекера, а не наличие сидов или начало передачи.
4. Проверьте другие торренты в том же клиенте. Рабочие соединения с пирами
   ослабляют гипотезу полной блокировки протокола, но не исключают выборочных
   ограничений или проблем с отдельным направлением.
5. Проверьте маршрут внутри Docker и LXC, переменные proxy, настройки шлюза.
   Обычный маршрут до роутера сам по себе не доказывает отсутствие VPN дальше.
6. Сравнение HTTP-трекера напрямую и через прокси проверяет только HTTP-доступность.
   Для проверки блокировки P2P требуется отдельное сравнение реального peer-трафика
   одного и того же роя по двум маршрутам. SOCKS для HTTP не равнозначен VPN для TCP/UDP.
7. Проверьте `peer-port`, публикацию TCP/UDP-порта Docker и внешний `port-test`.
   Если порт закрыт, выясните NAT, межсетевой экран и наличие публичного адреса
   (CGNAT/двойной NAT). Закрытый порт сокращает доступность входящих соединений,
   но сам по себе не должен запрещать все исходящие соединения.

## Наблюдение на домашней установке, 2026-11-06

Для третьего сезона «12 обезьян» версии RuTor и Kinozal имели одинаковый infohash,
версия LostFilm.tv — другой. После добавления трекеров передачи всё ещё не было;
несколько трекеров успешно отвечали и сообщали ноль сидов. Каталог RuTor показывал
три. Это согласуется с устаревшей статистикой или недоступными раздающими, но не
устанавливает окончательную причину. Другие торренты того же Transmission имели
соединения с пирами. Внешний тест входящего peer-порта показал закрытый порт.
HTTP-проверка нескольких трекеров через разные маршруты не выявила доказательства
общей блокировки BitTorrent; сравнение реального скачивания через VPN не выполнено.

Проблему нельзя считать решённой до наблюдаемого роста счётчика принятых байтов.
